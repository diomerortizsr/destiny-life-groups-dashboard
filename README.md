# Destiny Church — Life Groups Interest Dashboard

Interactive dashboard for the Life Groups interest form responses from Zapier.

**Live public URL (after Pages is enabled):**  
https://diomerortizsr.github.io/destiny-life-groups-dashboard/

### Features
- Full filters (location, age, marital status, has children, spiritually equipped, free-text search)
- KPI cards
- Charts: location bar, age doughnut, marital pie, top life-group interests
- Searchable / filterable table
- Download filtered data as CSV
- Destiny Church branding

Data is a snapshot of the Zapier table. Refresh the page for the current embedded snapshot.

Open `index.html` or the live GitHub Pages link once enabled.
